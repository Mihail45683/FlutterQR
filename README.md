# Генератор QR-кодов в PDF (Flutter)

## Запуск проекта

1. Убедитесь, что у вас установлен Flutter SDK.
2. В папке с проектом выполните команду для генерации нативных папок платформ (Android, iOS, Web, Windows и др.):
   ```bash
   flutter create .
   ```
3. Установите зависимости:
   ```bash
   flutter pub get
   ```
4. Запустите приложение:
   ```bash
   flutter run
   ```
